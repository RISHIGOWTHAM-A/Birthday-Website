# Emily's Birthday Website 🤎
npm install → npm run dev (local) → npm run build (deploy `dist/` to Vercel/Netlify/GitHub Pages)

Edit everything in `src/config/birthday.ts` (date, letters, notes, games).
Add photos to `public/images/` (profile, hero, memory-1..6 .jpg) and audio to `public/audio/`
(special-song.mp3, voice-note.mp3, pop/click/success/spin.mp3). Missing files fall back gracefully.
